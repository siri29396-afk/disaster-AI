# DisasterAI - Project Skills and Instructions

## Project Identity

Name: DisasterAI
Tagline: Prepared Today. Protected Tomorrow.

## Objective

Build an offline-first AI disaster preparedness application
powered exclusively by OpenAI for generative AI functionality.

## Core Capabilities

### 1. Disaster Assistance
- Answer preparedness-related questions.
- Explain natural disaster safety measures.
- Provide clear and understandable information.

### 2. Personalized Preparedness
- Generate household preparedness plans.
- Create emergency supply checklists.
- Support different disaster categories.

### 3. Multilingual Assistance
- English
- Telugu
- Hindi

### 4. Offline Emergency Mode
- Cache essential application resources.
- Store previously generated plans locally.
- Provide preloaded disaster safety guidelines.
- Display connectivity status.
- Never claim that OpenAI generation works offline.

### 5. Disaster Readiness Assessment
- Ask preparedness-related questions.
- Identify missing preparations.
- Generate recommendations.
- Explain that readiness scores are illustrative.

## Safety Requirements

- Never fabricate live emergency alerts.
- Never invent evacuation routes.
- Never provide unverified emergency numbers.
- Prefer official disaster management information.
- Display source and last-updated information for alerts.
- Clearly separate AI advice from official instructions.
- Direct users to emergency services during emergencies.

## Technical Requirements

Frontend: HTML, CSS, JavaScript
Backend: Python, FastAPI
AI Provider: OpenAI
Offline Storage: Browser localStorage
Offline Caching: Service Worker
Deployment: HTTPS-enabled hosting

## Expected Outcome

A functional disaster preparedness assistant that combines
AI-powered online guidance with accessible offline resources.
